# PartyPup marketing website

Responsive single-page site for PartyPup, which coordinates party services and venue bookings across selected Bengaluru East neighborhoods.

## Preview
Open index.html in a browser. The site uses plain HTML, CSS, and JavaScript with no build step.

## Included
- PartyPup identity, logo, and a new birthday-party hero photograph
- Party services including cakes, catering, decor, photography, venues, and extras
- Kids, teen, birthday, and anniversary celebrations
- Bengaluru service areas and a coming-soon location note
- Animated party brief → AI service matching → vendor confirmation → quote demo
- Plain-language party prompt with optional browser speech recognition
- Testimonials section ready for real customer feedback
- Party enquiry form and separate query/feedback form

## Before launch
The forms currently capture enquiries only. Connect the PartyPup AI layer, vendor availability/pricing workflow, booking flow, and quote delivery backend before presenting them as live functionality. The forms use Netlify Forms markup; connect a handler on other hosts. Browser speech recognition support varies, and browser providers may process speech data.

The 10-minute quote timing is shown as a service target. Confirm the operational SLA before publishing it as a guarantee.
